# AmbientWin releases

Signed Windows installers for [Ambient](https://danconiaindustry.com/ambient/).
Artifacts only - the source lives in the (private) AmbientWin repo, and the
updater feed is https://danconiaindustry.com/ambient/windows/latest.json.
Every installer is Authenticode-signed (CN=Joel Tenesaca) and carries a
minisign .sig verified by the in-app updater.
